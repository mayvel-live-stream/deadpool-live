# Deadpool.Live - ジョーク＆セキュリティ啓発サイト

このウェブサイトは、ネットゲーム **『マーベルライバルズ (Marvel Rivals)』** のプレイヤー **「デッドプール.Live」** にちなんだ、ファンメイドのジョーク＆セキュリティ啓発用サイトです。

怪しいログイン画面や偽のブルースクリーン（BSoD）演出を通じて、「知らないサイトで安易にパスワードを入力してはいけない」というフィッシング詐欺への注意喚起を行うことができます。

---

## 📂 ファイル構成
- `index.html` : サイトの骨組み（ログイン画面、BSoD、警告画面）
- `style.css` : デザイン、レイアウト、およびグリッチエフェクトアニメーション
- `script.js` : 各演出フェーズの切り替え、タイマー、進捗率の計算、コピー機能のロジック

---

## ⚡ 一般公開（インターネットデプロイ）の手順

本サイトをインターネット上に公開し、友達にアクセスしてもらうためには、以下のいずれかの方法で無料ホスティングサービスにアップロードするのが最も簡単でおすすめです。

### 方法1：Netlify にドラッグ＆ドロップで公開する（最も簡単）
1. [Netlify](https://www.netlify.com/) にアクセスし、無料アカウントを作成またはログインします。
2. ログイン後、ダッシュボードの「Add a new site」から **「Deploy manually」** を選択します。
3. このプロジェクトフォルダ（`deadpool-live`）ごと、ブラウザ上のドラッグ＆ドロップエリアに放り込みます。
4. 数秒でデプロイが完了し、`https://xxxxxx.netlify.app` のようなランダムなURLが発行され、公開が完了します！

### 方法2：Vercel にデプロイする
1. [Vercel](https://vercel.com/) にアクセスし、無料アカウントを作成します。
2. Vercel CLI を使うか、本プロジェクトを GitHub リポジトリにプッシュします。
3. Vercelのダッシュボードから該当するGitHubリポジトリをインポートするだけで、数クリックで公開完了します。

## 🔗 パロディドメイン（独自ドメイン）の割り当て手順
URLの時点でジョークだと気づかせるためのパロディドメイン（例：`tw1tch.live` や `marvelrivals-live.com`）を取得して割り当てる手順です。

1. **ドメインの取得**
   - [お名前.com](https://www.onamae.com/) や [Cloudflare Registrar](https://www.cloudflare.com/ja-jp/products/registrar/) などのドメイン登録サービスで、好みのパロディドメイン（例：`tw1tch.live`）を検索・取得します。
2. **ホスティングサービスとの紐付け**
   - **Netlify の場合**:
     - Netlifyの管理画面から「Domain settings」>「Add custom domain」に進み、取得したドメインを入力します。
     - 画面に指示された DNSレコード（CNAME や Aレコード）を、ドメインを取得したサービス側（お名前.comなどのDNS管理画面）に登録します。
   - **Vercel の場合**:
     - プロジェクトの「Settings」>「Domains」からドメインを追加し、同様に DNS レコードを設定します。
3. **SSL（HTTPS）の設定**
   - NetlifyやVercelでは、ドメインの紐付けが完了すると自動的に無料のSSL証明書（Let's Encrypt）が適用され、`https://` で安全に接続できるようになります。

## 🔒 セキュリティとプライバシーについて（安心設計）
本サイトのログインフォームに入力されたデータ（IDやパスワード）は、一切外部のサーバーに送信されず、ログファイル等にも保存されません。
`script.js` 内で送信イベント（`submit`）を即座にインターセプトし、メモリ上での処理のみで完結させているため、入力された情報はグリッチの開始と同時に完全に破棄されます。一般公開時も安心してご利用いただけます。
